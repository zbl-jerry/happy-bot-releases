# Happy Bot — downloads

Happy Bot is a desktop app for running your own team of AI agents. Each Bot has its own
folder, memory and browser; the app runs locally, and an account adds hosted models, phone
access and billing. The phone app pairs with your computer through an encrypted relay, so
the computer opens no port.

This repository only hosts **release builds**. The source code is kept private.

## Download

| Platform | File | Link |
| --- | --- | --- |
| macOS (Apple silicon) | `Happy-Bot-<version>-macos-arm64.zip` | [Latest release](../../releases/latest) |
| Android (arm64) | `Happy-Bot-<version>-android-arm64.apk` | [Latest release](../../releases/latest) |

- **macOS**: unzip, move `Happy Bot.app` to Applications, then open it. Builds are unsigned
  for now, so the first launch needs System Settings → Privacy & Security → Open Anyway.
- **Android**: install the APK, allow installation from unknown sources, then scan the
  pairing code shown in Happy Bot → Settings → Phone.

The desktop app checks this repository for updates. Only macOS arm64 and Android arm64 are
published today; Windows and Linux builds are not available yet.
